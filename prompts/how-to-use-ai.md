# 用AI一步步完成项目（实战流程）

核心模式：把目标讲清楚 → AI拆解步骤 → 逐步实现、逐步验收 → 报错直接丢给AI。
AI是执行搭档，你负责目标、判断和验收。

## 标准流程

1. **开场**：告诉AI三件事——要做什么、环境（系统 / Python版本 / 工具）、完成标准。
   例："在Windows上帮我把这个仓库的conda环境建好并在PyCharm里配好解释器，验收是终端能跑通 `python -c "import torch"`。"
2. **拆解**：让AI给出步骤清单，确认或调整顺序。
3. **逐步执行**：一次只推进一步，每步跑通、检查输出后再进行下一步；不行就回退。
4. **遇错**：完整报错 + 相关代码直接贴给AI，定位并修复；修完追问一句"为什么会这样"。
5. **验收**：对照第1步的完成标准逐条检查，全部通过才算完成。

## 原则

- 小步走：步子越小，AI翻车越好救
- 每步留痕：完成的步骤用 commit 和笔记记下来
- 看不懂的代码当场问，不留到以后
- 新问题新开会话，一次会话专注一件事

本仓库的环境三步（PyCharm → conda环境 → GitHub推送）就是按这个流程走的。
